# Local Typeless 安裝指南（Windows）

這份指南帶你從零裝好並開始使用。設定細節（換模型、GPU、公司內部 gateway）請看 [設定手冊](./設定手冊.md)；會安裝哪些套件請看 [套件清單](./套件清單.md)。

## 1. 事前準備

- Windows 10 或 11（64 位元）
- Python 3.10 以上（需包含 Tkinter，python.org 安裝程式預設會裝）。安裝時勾選「Add python.exe to PATH」
- 可用的麥克風
- 可連到的 LLM 服務（自架的 OpenAI 相容服務，或公司內部 gateway）。連不上也能用：會輸出經詞庫校正的原始逐字稿

> 語音辨識完全在本機執行，音訊與圖片不會離開這台電腦。LLM 只收到文字，請只設定內部服務，不要填第三方雲端 API。

## 2. 安裝

1. 把整個專案資料夾放到你想要的位置（例如 `D:\Tools\localtypeless`）。
2. 在該資料夾開啟 PowerShell，執行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\install.ps1 -Shortcut
   ```

安裝腳本會依序做這些事，重複執行不會弄壞既有設定：

1. 檢查 Python 版本與 Tkinter
2. 建立 `.venv` 虛擬環境（已存在就略過）
3. 安裝本專案與相依套件（完整清單見 [套件清單](./套件清單.md)）
4. 若沒有 `config\config.yaml`，從 `config\config.example.yaml` 複製一份
5. 下載語音模型權重（只在這一步連線下載，不會傳送任何音訊）
6. 加了 `-Shortcut` 時，在桌面建立「Local Typeless」捷徑

可用參數：

| 參數 | 作用 |
|---|---|
| `-SttProfile cpu_accurate` | 改下載該 profile 用的模型（預設 `cpu_fast`） |
| `-SkipModel` | 不下載模型（離線安裝用，見第 6 節） |
| `-Shortcut` | 建立桌面捷徑 |

## 3. 設定 LLM

用記事本開啟 `config\config.yaml`：

```yaml
active_llm_profile: dev        # dev = 自架服務；corp = 公司內部 gateway

llm_profiles:
  dev:
    base_url: http://<你的 LLM 服務位址>:8000/v1
    api_key_env: DGX_API_KEY   # 金鑰放在這個環境變數裡，不寫進設定檔
    model: <伺服器上的模型名稱>
```

設定金鑰環境變數（只需做一次，之後重新啟動面板）：

```powershell
[Environment]::SetEnvironmentVariable('DGX_API_KEY', '<你的金鑰>', 'User')
```

伺服器不需要金鑰時，可以不設定這個變數。

## 4. 檢查與啟動

檢查設定、CUDA 與 LLM 連線（會實際送一次極短的測試請求，失敗時會提示該改哪個設定）：

```powershell
.venv\Scripts\python.exe -m local_typeless.cli check
```

啟動面板，三種方式擇一：

| 方式 | 說明 |
|---|---|
| 桌面捷徑或雙擊 `LocalTypeless.vbs` | 日常使用，沒有黑色視窗 |
| 雙擊 `start_ui.bat` | 會開主控台視窗，方便看訊息 |
| `.venv\Scripts\python.exe -m local_typeless.ui` | 可加 `--stt-profile`、`--device` 等參數 |

面板會停靠在螢幕右側，點它不會搶走文件的游標。執行紀錄在 `records\cache\ui.log`。

## 5. 開始使用

### 快捷鍵

| 快捷鍵 | 作用 |
|---|---|
| `Alt+Q` | 整理模式：開始錄音，再按一次結束（預設模式） |
| `Alt+W` | 摘要模式：開始／結束錄音 |
| `Alt+S` | 投影片模式：開始／結束錄音 |
| `Alt+V` | 錄音中：把剪貼簿裡的圖片插入到目前說到的位置 |
| `Esc` | 錄音中：取消這段錄音 |

快捷鍵可在 `config\config.yaml` 的 `hotkeys` 區段修改。面板上的按鈕也會顯示對應的快捷鍵。

### 邊講邊插圖

1. 先截圖（`Win+Shift+S`）或複製一張圖片。錄音前或錄音中做都可以。
2. 講到要放圖的地方，按 `Alt+V`（或面板的「貼上圖片」）。面板會顯示 `圖×1`。
3. 繼續講。結束後，結果會依序貼成「文字 → 圖片 → 文字」。

例如說「按照」→ 按 `Alt+V` →「的風格做改動」，會得到 `按照 [圖片] 的風格做改動`。

貼上目標若是純文字欄位（記事本、終端機），圖片貼不進去，文字不受影響。

### 長口述

錄音時就會在背景分段辨識，面板即時顯示逐字稿。按下結束後可以馬上錄下一段，結果會依序貼上；如果上一段完成時你正在錄音，會等你錄完再貼。

## 6. 離線安裝（無法連外網的電腦）

1. 在可連網的電腦上完成第 2 節的安裝，確認可用。
2. 取得模型資料夾：模型下載後位於 `%USERPROFILE%\.cache\huggingface\hub\` 底下。把對應的模型資料夾複製到目標電腦。
3. 在目標電腦安裝時加上 `-SkipModel`，然後在 `config\config.yaml` 的 STT profile 設定模型資料夾：

   ```yaml
   stt_profiles:
     cpu_fast:
       model_path: D:\models\faster-whisper-small
   ```

公司若有內部 Hugging Face 鏡像，可先設定環境變數 `HF_ENDPOINT` 指向鏡像，再執行下載指令：

```powershell
.venv\Scripts\python.exe -m local_typeless.cli download-model --stt-profile cpu_fast
```

相依套件在離線環境的安裝方式取決於公司的套件來源（內部 PyPI 鏡像或事先打包的 wheel），請依公司規定處理。

## 7. 紀錄、圖片與暫存檔存在哪裡

每次口述完成都會存成一個 Markdown 檔，預設位置在專案資料夾內：

```
records\
├── 2026-11\
│   └── 20261112-143005_整理_今天先講 ILT 的基本概念.md
├── images\
│   └── 20261112-142950-a1b2c3\
│       └── img_1.png
└── cache\                 ← 暫存檔：最近一次錄音、面板歷史、執行紀錄
```

- 檔名格式為「日期-時間_模式_開頭文字」。
- 檔案內有整理後的結果（圖片以連結呈現）與原始逐字稿。
- 超過 90 天的紀錄與圖片會自動刪除。只會刪除本工具自己建立的檔案。

暫存檔的大小有上限，不會無限增加（各項說明見設定手冊 4.5）。

位置、保留天數與檔名格式都可以在 `config\config.yaml` 修改：

```yaml
cache_dir: D:\Dictation\cache           # 暫存檔（最近一次錄音、歷史、執行紀錄）

storage:
  records_dir: D:\Dictation\records     # 文字紀錄
  images_dir: D:\Dictation\images       # 圖片
  retention_days: 90                    # 0 表示永久保留
  filename_format: "{date}-{time}_{mode}_{title}"
```

## 8. 升級與移除

**升級**：用新版檔案覆蓋專案資料夾（`config\config.yaml` 與 `records\` 會保留），再執行一次 `scripts\install.ps1 -SkipModel`。

**移除**：關閉面板，刪除桌面捷徑與整個專案資料夾即可。若想一併清掉語音模型，刪除 `%USERPROFILE%\.cache\huggingface\hub\` 底下對應的模型資料夾。

## 9. 常見問題

| 狀況 | 處理方式 |
|---|---|
| 面板提示「STT 模型尚未下載」 | 執行提示中的 `download-model` 指令，或設定 `model_path` |
| 狀態列顯示「金鑰錯誤或未設定」 | 確認 `api_key_env` 指到的環境變數已設定，然後重新啟動面板 |
| 狀態列顯示「無法連線」或「連線逾時」 | 確認 LLM 服務與網路（VPN）正常；必要時調高 `timeout_sec` |
| 結果是未整理的原文 | LLM 連線失敗時的保護機制，內容不會遺失；恢復連線後可按「重試上一段」 |
| 按 `Alt+V` 顯示「剪貼簿沒有圖片」 | 先截圖或複製圖片，再按一次 |
| 圖片貼上的順序不對或漏貼 | 調高 `output.paste_step_delay_ms`（例如 500） |
| 快捷鍵沒反應 | 面板會顯示「全域快捷鍵無法使用」；確認沒有其他程式佔用同一組按鍵，或改用面板按鈕 |
| 雙擊 `start_ui.bat` 顯示找不到虛擬環境 | 尚未安裝，請先執行 `scripts\install.ps1` |
