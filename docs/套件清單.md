# 套件清單

這份清單列出安裝本工具時會裝到電腦上的所有東西，方便在安裝前送審或自行評估。

版本是 2026-11-12 在全新資料夾執行 `scripts\install.ps1`（Windows 11、Python 3.13）實際裝到的版本。
`pyproject.toml` 沒有鎖定版本，日後安裝會取得當時的最新相容版本；要取得自己環境的實際清單，執行：

```
.venv\Scripts\python.exe -m pip list
```

## 4. 語音模型（從 Hugging Face 下載一次）

依選用的 STT profile 下載，存放在 `%USERPROFILE%\.cache\huggingface\hub\`：

| STT profile | 模型 | 來源 |
|---|---|---|
| `cpu_fast`（預設） | Whisper small | `Systran/faster-whisper-small` |
| `cpu_accurate`、`gpu_local` | Whisper large-v3-turbo | `mobiuslabsgmbh/faster-whisper-large-v3-turbo` |

Whisper 模型權重為 MIT 授權。語音活動偵測用的 Silero VAD 模型已包含在 faster-whisper 套件內，不另外下載。
無法連外網時的做法見[安裝指南](./安裝指南.md)第 6 節。

## 5. 選用：GPU

只有使用 `gpu_local` profile 時才需要，安裝腳本不會安裝：

| 套件 | 用途 |
|---|---|
| nvidia-cublas-cu12 | CUDA 12 的 cuBLAS 執行階段 |
| nvidia-cudnn-cu12 | cuDNN 執行階段 |

這兩個套件採 NVIDIA 專有授權。沒有安裝或 GPU 無法使用時，程式會自動改用 CPU。安裝方式見[設定手冊](./設定手冊.md)。

## 6. 選用：開發與測試

執行測試才需要，以 `.venv\Scripts\python.exe -m pip install -e ".[dev]"` 安裝：

| 套件 | 用途 |
|---|---|
| pytest | 測試執行 |
| pytest-mock | 測試替身 |
| respx | 模擬 HTTP 回應 |

## 7. 安裝與執行時會連線到哪裡

| 時機 | 連線對象 | 傳送的內容 |
|---|---|---|
| 安裝 | Python 套件來源（預設 pypi.org，或你設定的內部鏡像） | 無使用者資料 |
| 下載模型（一次） | huggingface.co，或 `HF_ENDPOINT` 指定的鏡像 | 無使用者資料 |
| 使用中 | 你在 `config.yaml` 設定的 LLM 服務 | 辨識後的文字。音訊與圖片不會送出 |

使用中會強制 `HF_HUB_OFFLINE=1` 並關閉 Hugging Face 遙測，程式不會連到上表以外的地方。
